# Zajícova korýtka

Moderní responzivní web pro značku Zajícova korýtka — poctivá korýtka, catering a obložené mísy.

## Spuštění

Stačí otevřít `index.html` v prohlížeči, nebo lokální server:

```bash
npx serve .
# nebo
python3 -m http.server 8080
```

## Struktura

- `index.html` — obsah a SEO
- `styles.css` — design systém a layout
- `script.js` — navigace, animace, formulář
- `assets/images/` — fotografie
- `assets/icons/` — maskot zajíce a ikony

## Formulář

Poptávka otevírá e-mailový klient (`mailto:info@zajicovakorytka.cz`). Adresu upravte v `script.js` podle skutečného kontaktu.
